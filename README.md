# 🌿 한의원 치료 후기 앱 (PWA)

치료를 마친 환자가 QR코드로 접속해 후기를 남기고, 원장님이 답글을 달 수 있는 앱입니다.
외부 라이브러리 없이 Node.js(18+)만으로 동작합니다.

## 실행
```bash
ADMIN_PASSWORD=나만의비밀번호 node server.js
# 환자용: http://localhost:3000/    관리자: http://localhost:3000/admin
```
- 후기 데이터는 `data/reviews.json`에 저장됩니다 (정기 백업 권장).
- **실제 환자가 쓰려면 HTTPS 주소로 배포해야 합니다** (PWA 설치/서비스워커 조건). Render, Railway, Fly.io 등 Node를 돌릴 수 있는 곳에 올리고 영구 디스크(Volume)에 `DATA_DIR`을 지정하세요.
- Render 배포: 저장소 연결 후 New → Blueprint 로 `render.yaml` 사용 (ADMIN_PASSWORD만 입력)
- 환경변수: `CLINIC_NAME`(화면에 표시될 한의원 이름), `ADMIN_PASSWORD`(필수 변경), `SESSION_SECRET`(권장), `PORT`, `DATA_DIR`

## QR 코드
`/admin` 로그인 → **QR 코드** 탭에서 배포된 주소를 넣으면 QR 생성, 안내 포스터 인쇄, PNG 저장이 됩니다.

## 질문 바꾸기
`public/config.js` 한 파일에서 선택지, 질문 순서/문구를 수정합니다.

## 소통 구조
1. 환자가 후기 제출 → 기기에 비밀 토큰 저장 (이름·연락처 불필요)
2. 관리자가 후기별로 답글 작성
3. 환자는 앱의 "내 후기 답글 확인"에서 답글 확인

## 개인정보 유의
연락처(선택)를 받으면 개인정보 수집에 해당합니다. 사용 시 안내 문구와 보관 기간 정책을 정해 두세요.

## 텔레그램 새 후기 알림 (선택)
1. 텔레그램에서 `@BotFather` → `/newbot` 으로 봇을 만들고 **토큰**을 받습니다.
2. 직원방에 봇을 초대하고 방에서 아무 말이나 합니다.
3. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates` 를 열어 `"chat":{"id":...}` 의 숫자가 **채팅 ID**입니다 (그룹은 `-`로 시작).
4. `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` 환경변수를 설정합니다. (`PUBLIC_URL`은 Render에서 자동 인식)
- 알림에는 점수 요약만 가고, 후기 본문·이름·연락처는 포함되지 않습니다.

## 💊 한약 진행 관리 (직원용, `/herb`)
중복 조제·처방전 없는 발송을 막기 위한 직원용 화면입니다. 같은 서버에 함께 들어 있어요.

- 주소: `배포주소/herb` (휴대폰에 **앱으로 설치** 가능: 설정 탭 안내, 아이폰은 사파리 공유 → 홈 화면에 추가) → 직원 공용 비밀번호(`STAFF_PASSWORD`, 없으면 `ADMIN_PASSWORD`) → 본인 이름 선택
- 환자 1명 1회차 = 카드 1장. 상태: 처방전 필요 → 처방전 받음 → 조제중(담당자) → 조제완료·보관(위치) → 발송·수령 완료 (+ 보류, 회수 필요)
- 서버가 강제하는 규칙
  1. 처방전 받음 상태가 아니면 **조제 시작 불가**
  2. 다른 사람이 조제중인 카드는 되돌릴 수 없음, 누가 조제했는지 자동 기록
  3. **조제완료(보관 위치 필수)** 된 약만 발송 가능, 발송 직전 이름·처방 대조 체크
  4. 같은 환자·같은 회차 카드가 진행 중이면 새로 만들 때 경고 (중복 조제 방지)
  5. 두 사람이 동시에 같은 카드를 바꾸면 나중 사람은 거절됨
- **오늘 요약(단톡용)** 탭: 단톡방에 매일 올리던 양식을 자동 생성 → 복사해서 붙여넣기
- **포장재(파우치·택배 박스·쌍화탕 박스) 재고**: 조제완료 때 쓴 파우치·박스 수, 택배 발송 때 택배 박스 수(기본 1)를 입력하면 자동 차감
  - 품목별 최소 수량 설정 → 아래로 내려가면 진행판 맨 위와 단톡 요약에 "주문/제작 필요" 경고
  - 입고(+), 실사(직접 센 수량으로 맞추기), 누가·왜 바꿨는지 재고 변동 기록
- **다음 회차 자동 생성**: n회차를 발송하면 (n+1)회차 카드가 '처방전 필요'로 자동 생성. 기존 환자 이름을 치면 다음 회차·처방·받는 방법 자동 입력
- **오케이차트(스마트애니웨어) 연결 버튼**: `/herb-link.html` (설정 탭에 링크)
  - 차트 처방 화면에서 즐겨찾기 버튼 [한약카드]를 누르면 화면의 환자 이름·처방·차트번호 후보를 읽어 새 카드에 채움
  - 차트 계정 정보는 읽거나 저장하지 않음. 읽은 내용은 주소의 `#` 뒤로 직원 브라우저 안에서만 전달(서버 로그에 안 남음)
  - 차트 화면 구조에 맞춘 정밀 조정은 `public/okchart-bookmarklet.js`에서
- **⏰ 15일 알람** (첫 화면): 한약 **출발일**부터 15일마다 알람. 발송 처리한 카드는 자동으로, 그 밖에는 이름+출발일만 직접 등록
  - `확인 완료` → 다음 15일 시점에 다시 알람 / `알람 끝내기` → 종료
  - 연락처(선택)를 넣으면 휴대폰에서 문구가 채워진 문자 화면 열기. **환자에게 자동 발송(알림톡)은 하지 않음**
  - 텔레그램 설정 시 매일 오전 9시 이후 한 번 직원방에 알림 (이름은 가려서 전송, 예: 김○수)
  - 환자는 이름으로 구분하므로 동명이인은 `김철수A`처럼 구분해서 입력
- **로젠 송장 + 배송 알림톡**
  - 택배 카드는 조제 시작부터 `📦 로젠 접수 필요` 표시, 진행판 위에 "로젠 접수할 택배 N건"
  - 송장번호 입력(휴대폰 크롬은 바코드 스캔) 전에는 발송 불가, 같은 송장번호 두 카드에 넣으면 거절
  - 발송 시 연락처 + 수신동의 + 솔라피 설정이 모두 있으면 배송 안내 알림톡 자동 발송, 결과는 카드에 기록
  - 템플릿 문구·환경변수·수신동의서: `templates/알림톡_템플릿_및_수신동의.md`
- **📷 사진으로 카드 만들기**: 진행판의 "사진 찍어서 새 카드" → 차트 화면이나 처방전을 찍으면 이름·처방·회차·휴대폰·차트번호를 읽어 채움 (직원이 확인 후 만들기)
  - Claude API 사용 (`ANTHROPIC_API_KEY`, 모델은 `PHOTO_READ_MODEL`로 변경 가능). 키가 없으면 버튼이 안 보임
  - 사진은 서버에 저장하지 않고 읽기 요청에만 씀. 주소·주민번호·진단명은 옮기지 않도록 지시
- **결제 패키지 일수**: 새 카드에서 30·60·90·180일 또는 직접 입력 → 총 회차(일수÷15, 올림)와 종료일 자동 계산, 다음 회차 카드에 이어짐
- **💊 복용법**: 카드에서 하루 몇 번 · 식전/식후/식간/자기 전 · 1회량을 버튼으로 고르면 문장 자동 작성, 처방별로 기억해 다음 환자에 자동 채움 → 시작 인사·발송 알림톡(`#{복용법}`)과 조제 사진 페이지에 표시
- **결제 첫날 시작 인사**: 환자의 첫 카드(1회차)를 만들면 수신동의 시 "최선을 다하겠습니다" 알림톡 자동 발송 (`ALIMTALK_TPL_WELCOME`)
- **🏷 조제 사진 한꺼번에 올리기**: 진행판 버튼 → 단톡방에 올리던 라벨·저울 사진을 순서대로 여러 장 선택 → 라벨 이름으로 카드에 자동 배정, 저울 숫자는 무게(g)로 기록 → 확인 한 번에 조제완료 (처방전 없는 카드는 막음)
  - 라벨 사진만 환자 페이지·카톡에 나가고, 저울 사진은 직원용 내부 기록
- **회차별 조제 알림**: 결제 때 1/6이면 1회차는 결제일, 2~6회차는 직전 발송 10일 뒤(약 떨어지기 5일 전, `HERB_PREP_DAYS`로 변경)가 조제 알림일 → 그날 오전 직원 폰에 "N회차 조제할 차례" (6회차면 6번). 카드 상세에서 예정일 변경 가능
- **📷 한약 사진 카톡**: 조제완료 때 카메라로 바로 찍기 → 환자에게 비공개 링크(60일)로 사진 안내 알림톡. 카드의 "📷 사진"으로 추가·재발송
- **15일 안부 + 설문**: 알람 날 오전 수신동의 환자에게 자동 카톡(설문 링크), 응답은 알람 카드에 표시, 연락 필요 답변은 즉시 푸시
- **🔔 휴대폰 푸시 알림** (설정 탭 → 이 폰 알림 켜기): 조제할 약, 로젠 접수 필요, 회수, 재고 부족, 알림톡 실패, 아침 15일 확인 요약
  - 잠금화면용이라 이름은 가림(김○수), 본인이 한 일은 본인 폰에 안 감
  - 아이폰은 홈 화면에 앱으로 설치한 뒤에만 가능 (iOS 16.4+)
  - 키(VAPID)는 `DATA_DIR/vapid.json`에 자동 생성. 지우거나 바뀌면 직원들이 알림을 다시 켜야 함
- **환자 탭**: 진행 중 / 진행 끝(마지막 회차 발송, 진행 중 카드 없음) 환자 구분, 재처방 카드 바로 만들기
  - 이번 분기 이벤트 안내 대상 = 진행 끝 + 휴대폰 + **이벤트(광고) 수신 동의**. 명단 CSV로 받아 솔라피 대량발송에 사용
- 상비 탕약 재고 +/−, 설정에서 직원 이름 관리, CSV(엑셀) 내보내기
- 데이터: `DATA_DIR/herb.json` (환자 이름 포함 → 정기 백업, 비밀번호 공유 범위 주의)

## 📄 서버 없이 쓰는 구글 시트 버전
`templates/한약진행관리.xlsx` → 구글 드라이브 업로드 → Google 스프레드시트로 저장 → 직원에게만 공유.
상태 드롭다운, 중복 회차/처방전 없는 조제·발송 자동 경고(빨간 줄), 상비재고(최소 수량 경고), **포장재 시트**(진행현황의 파우치·박스 사용 칸을 자동 합산해 현재 수량 계산), 사용법 시트 포함. 예시 줄(○예시)은 지우고 쓰세요.
