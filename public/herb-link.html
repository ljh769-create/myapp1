🔗 오케이차트 → 한약 카드 버튼

스마트애니웨어 처방 화면에서 이 버튼을 누르면 환자 이름·처방을 읽어 한약 앱의 새 카드에 채워 줍니다. 직원은 확인하고 "만들기"만 누르면 돼요.
차트 아이디·비밀번호는 읽지도 저장하지도 않습니다. 읽은 내용은 이 브라우저 안에서 한약 앱 화면으로만 넘어갑니다.

💻 PC (크롬·엣지)

  1. Ctrl + Shift + B 를 눌러 즐겨찾기 줄을 보이게 합니다.
  2. 아래 초록 버튼을 마우스로 끌어서 즐겨찾기 줄에 놓습니다. (클릭 X)
  3. 스마트애니웨어에서 환자 처방 화면을 연 상태로 즐겨찾기 줄의 [한약카드]를 누릅니다.

한약카드

이름을 더 정확히 잡으려면, 누르기 전에 차트 화면에서 환자 이름을 마우스로 드래그(선택)해 두세요. 선택한 글자를 1순위로 씁니다.

📱 휴대폰 (크롬)

  1. 아래 코드 복사를 누릅니다.
  2. 아무 페이지에서나 ☆(북마크 추가) → 방금 만든 북마크 수정.
  3. 이름은 한약카드, 주소(URL)는 전부 지우고 복사한 코드 붙여넣기 → 저장.
  4. 차트 처방 화면에서 주소창에 "한약카드"를 입력하고, 아래 목록에 뜨는 북마크(★ 한약카드)를 누릅니다.
