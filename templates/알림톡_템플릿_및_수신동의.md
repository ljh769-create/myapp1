# 알림톡 템플릿 & 수신 동의서

## 1. 솔라피에 등록할 템플릿: 한약 발송 안내

- 카테고리: 배송 > 배송 상태 (또는 의료 > 진료 안내)
- 메시지 유형: 기본형
- 강조 표기: 사용 안 함
- **광고성 문구(할인, 이벤트, 추천)는 넣지 마세요. 넣으면 심사에서 반려됩니다.**

```
[#{이름}님 한약 발송 안내]

안녕하세요, #{이름}님.
처방받으신 한약을 오늘 발송했습니다.

■ 처방: #{처방} #{회차}
■ 택배사: #{택배사}
■ 송장번호: #{송장번호}

배송 조회: #{조회링크}

받으신 뒤 바로 냉장 보관해 주세요.
복용 중 불편한 점이 있으면 채널 채팅으로 남겨 주세요.

※ 이 메시지는 한약 발송을 신청하신 분께 보내는 안내입니다.
```

- 버튼(선택): **배송조회** 버튼을 추가하면 카카오가 본문의 택배사와 송장번호를 읽어 조회 화면을 띄워 줍니다. 이 버튼을 넣었다면 본문의 `배송 조회: #{조회링크}` 줄은 지워도 됩니다. 단, 앱은 `#{조회링크}` 변수를 계속 보내므로, 줄을 지운 템플릿이 변수 불일치로 실패하지 않는지 시험 발송으로 확인하세요.
- 변수 이름은 위와 **정확히 같아야** 합니다: `#{이름}` `#{처방}` `#{회차}` `#{택배사}` `#{송장번호}` `#{조회링크}`
- 승인되면 템플릿 ID를 Render 환경변수 `ALIMTALK_TPL_SHIPPED`에 넣습니다.

## 2. Render 환경변수

| 이름 | 값 |
|---|---|
| `SOLAPI_API_KEY` / `SOLAPI_API_SECRET` | 솔라피 콘솔 → API Key 관리 |
| `SOLAPI_PFID` | 솔라피에 카카오 채널을 연동하면 나오는 pfId |
| `SOLAPI_FROM` | 솔라피에 등록한 발신번호 (한의원 대표번호). 알림톡 실패 시 문자로 대신 보냄. 비우면 문자 대체 안 함 |
| `ALIMTALK_TPL_SHIPPED` | 위 템플릿의 승인된 ID |
| `LOGEN_TRACK_URL` (선택) | 로젠 조회 주소가 바뀌었을 때만. 기본값 `https://www.ilogen.com/web/personal/trace/` |

하나라도 비어 있으면 알림톡은 꺼진 상태로 동작합니다. 앱은 정상적으로 쓸 수 있고, 카드에 "알림톡 미설정"으로 표시됩니다.

## 3. 수신 동의서 (접수대 비치 / 처방 상담 때 구두 확인 후 앱에 체크)

> **카카오 알림톡 수신 및 연락처 이용 동의**
>
> 1. 수집 항목: 성명, 휴대폰 번호
> 2. 이용 목적: 한약 조제·발송 안내, 배송 조회 안내, 복약 관련 안내
> 3. 보유 기간: 마지막 한약 발송일로부터 1년 (또는 동의 철회 시까지)
> 4. 발송 방법: 카카오톡 알림톡 (카카오톡을 쓰지 않거나 실패하면 문자로 대신 발송)
> 5. 동의를 거부할 수 있으며, 거부해도 진료와 한약 수령에는 불이익이 없습니다. 이 경우 배송 안내만 받지 못합니다.
>
> 위 내용에 동의합니다. &nbsp;&nbsp; 20 &nbsp;&nbsp;. &nbsp;&nbsp;. &nbsp;&nbsp;. &nbsp;&nbsp; 성명: ____________ (서명)

- 광고(이벤트·할인) 메시지는 이 동의로 보낼 수 없습니다. 보내려면 **광고성 정보 수신 동의**를 따로 받아야 하고, 의료광고 심의 대상이 될 수 있습니다.
- 동의서 문구는 예시입니다. 원장님 또는 개인정보 담당자가 확인한 뒤 쓰세요.

## 4. 이벤트·할인 안내 (광고성 정보) 수신 동의 — 위 동의와 **따로** 받기

> **광고성 정보(이벤트·할인 안내) 수신 동의 (선택)**
>
> 한의원의 이벤트, 할인, 건강 프로그램 안내를 카카오톡 또는 문자로 받는 데 동의합니다.
> 동의하지 않아도 진료와 한약 수령에는 불이익이 없으며, 언제든 수신을 거부할 수 있습니다.
>
> □ 동의합니다 &nbsp;&nbsp; □ 동의하지 않습니다

- 앱의 **환자 탭 → 분기 이벤트 대상**에는 이 동의에 체크한 환자만 나옵니다.
- 광고 메시지는 알림톡으로 보낼 수 없습니다. 솔라피의 **브랜드 메시지(친구톡)나 문자 대량발송**을 쓰세요. 메시지 앞에 `(광고)`, 끝에 수신거부 방법을 넣어야 하고, 밤 9시~아침 8시에는 보내지 않습니다.
- 할인·이벤트 문구는 **의료광고 사전심의** 대상이 될 수 있으니 보내기 전에 확인하세요.
